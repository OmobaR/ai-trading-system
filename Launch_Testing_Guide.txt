PHASE 0 — Pre-Flight Checks

Before launching anything:

1️⃣ Ensure Docker Desktop is running

TimescaleDB, Redis, Grafana, Prometheus all run via Docker

You must see Docker → "Running"

2️⃣ Activate Your Python Env

From project root:

cd C:\Users\olugb\ai-trading-system
.\ai_trading_env\Scripts\Activate.ps1

3️⃣ Ensure .env exists

If missing:

copy .env.example .env


Update DB, Redis, API keys as needed.

PHASE 1 — Start Infrastructure

Your new infrastructure lives in:

docker/compose/docker-compose.dev.yml

1️⃣ Start all services (DB, Redis, Grafana, Prometheus)
docker compose -f docker/compose/docker-compose.dev.yml up -d

2️⃣ Check status
docker compose -f docker/compose/docker-compose.dev.yml ps


Expect:

Service	Port
TimescaleDB	5432
Redis	6379
Grafana	3000
Prometheus	9090
Redis Commander	8081
3️⃣ Check logs quickly
docker compose -f docker/compose/docker-compose.dev.yml logs --tail 50

PHASE 2 — Initialize Database

Run your schema + hypertables:

psql -h localhost -U postgres -d ai_trading_db -f docker/compose/src/database/timescaledb_setup.sql


Password = password unless you changed it.

3.2 — Redis Feature Store Test
python - << "EOF"
from src.database.redis_feature_store import UnifiedRegimeFeatureStore
import pandas as pd, numpy as np

print("FeatureStore OK")

dates = pd.date_range("2024-01-01", periods=120, freq="H")
data = pd.DataFrame({
    "open": np.random.randn(120).cumsum()+100,
    "high": np.random.randn(120).cumsum()+100,
    "low":  np.random.randn(120).cumsum()+100,
    "close":np.random.randn(120).cumsum()+100,
    "tick_volume": np.random.randint(1000,9000,120)
}, index=dates)

print("Signals:", s)
EOF
